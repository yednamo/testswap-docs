# TestSwap: документація / documentation

[TestSwap](https://testswap.yednamo.com) — обмін тестуванням між розробниками Google Play: ви тестуєте чужі застосунки,
і ваш тестують реальні люди 14 днів, як вимагає Google для нових особистих акаунтів розробника.

TestSwap is a test exchange for Google Play developers: you test other apps, and real people test yours for 14 days,
as Google requires for new personal developer accounts.

## Українською

- [Тестувальнику](uk/tester.md): як взяти участь у тесті й отримати бали.
- [Розробнику](uk/developer.md): як розмістити застосунок і налаштувати Play Console.
- [SDK для Android](uk/sdk.md): автоматичне підтвердження встановлення й днів тесту.
- [Правила й бали](uk/rules.md).
