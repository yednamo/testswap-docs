# Правила й бали

| Подія | Бали |
|---|---|
| 14 днів тесту (тестувальнику) | +10 |
| Прийнятий відгук (тестувальнику) | +2 |
| Один тестувальник для вашого застосунку (розробнику) | −12 |
| Найменший допустимий баланс | −180 |

- Тест триває 14 днів, можна пропустити не більше 2.
- Відгук: щонайменше 80 символів, з 3-го дня тесту; після 14-го дня ще 3 дні на дописування.
- Відгук без рішення розробника 3 дні приймається автоматично.
- Одночасно: до 5 тестів на тестувальника, до 3 незакритих застосунків на розробника.
- Бали не мають грошової вартості й не обмінюються на гроші.

## Заборонено

Кілька акаунтів однієї людини, емулятори й ферми пристроїв, участь без встановлення, скопійовані або порожні
відгуки, обмін «участю» без реального користування застосунками. За порушення бали анулюються, акаунт блокується.
