# SDK для Android

SDK підтверджує, що тестувальник встановив застосунок з Google Play за особистим посиланням TestSwap, і
автоматично відмічає дні тесту. Підключення необов’язкове.

## Як це працює

1. Тестувальник отримує посилання виду
   `https://play.google.com/store/apps/details?id=<пакет>&referrer=ts_<токен>`.
2. Google Play передає мітку `ts_<токен>` застосунку через Install Referrer.
3. Під час першого запуску SDK надсилає на `https://testswap.yednamo.com/sdk/v1/install` ключ застосунку й мітку.
4. Далі під час запусків SDK надсилає `/sdk/v1/ping` (не частіше ніж раз на 3 години). Сервер рахує один день на добу
   за часовим поясом тестувальника.
5. Після завершення тесту SDK припиняє надсилати запити.

Користувачі, які встановили застосунок не за посиланням TestSwap, нічого не надсилають.

## Підключення

```kotlin
// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://jitpack.io") }
    }
}
```

```kotlin
// app/build.gradle.kts
dependencies {
    implementation("com.github.yednamo:testswap-sdk-android:0.1.0")
}
```

```kotlin
class App : Application() {
    override fun onCreate() {
        super.onCreate()
        TestSwap.init(this, "tsk_...") // ключ із кабінету застосунку в TestSwap
    }
}
```

Не забудьте вказати клас `App` в `AndroidManifest.xml` (`android:name=".App"`). Бібліотека додає дозвіл `INTERNET`.

## Дані

Надсилаються лише ключ застосунку (публічний, вбудований у збірку), токен участі й версія SDK. Ідентифікатори пристрою,
рекламні ідентифікатори й дані користувача не надсилаються.

Якщо ваш застосунок раніше працював без інтернету, підключення SDK додасть дозвіл `INTERNET`. Оновіть політику
конфіденційності й розділ Data safety у Play Console. Для таких застосунків простіше обрати режим без SDK.

## Перевірка

1. Розмістіть застосунок у режимі «З SDK» і скопіюйте ключ.
2. Приєднайтеся до тесту з іншого акаунта, встановіть застосунок за особистим посиланням і відкрийте його.
3. На сторінці тесту має з’явитися «Застосунок підтвердив встановлення», а день — позначка SDK.
